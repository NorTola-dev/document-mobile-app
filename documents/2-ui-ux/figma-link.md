## 🎨 Design System

All members must use the same design system.

### Colors

* Primary
* Secondary
* Background
* Surface
* Text
* Secondary Text
* Success
* Warning
* Error

### Typography

The team should use one consistent font family.

```text
Heading
Subtitle
Body
Caption
Button
```

### Components

Common components should be created in:

```text
01 Design System
└── Components
```

Examples:

* Buttons
* Text Fields
* Search Bar
* Cards
* Chips
* Dropdowns
* Navigation
* App Bar
* Bottom Navigation
* Dialog
* Bottom Sheet

## 📝 Design Rules

Before creating or changing a screen:

1. Check the Design System.
2. Reuse existing components.
3. Follow the same colors.
4. Follow the same typography.
5. Follow the same spacing.
6. Keep the same naming convention.
7. Do not duplicate existing screens.
8. Discuss major changes with the team.
